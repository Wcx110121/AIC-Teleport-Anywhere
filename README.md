# Teleport Anywhere

为 Alice in Cradle 0.30 提供跨地图、跨区域快捷传送。模组通过游戏原有的事件系统执行地图加载、落点校正与区域切换。独立 C# 插件，无需 Node 或额外运行时。

## 使用方法

- 将 `TeleportAnywhere.dll` 放入 `BepInEx/plugins/TeleportAnywhere/`。需要 Alice in Cradle 0.30 和 BepInEx 5 Mono。
- **0.2.2 直接使用原版地图，没有独立菜单或悬浮入口，也不需要 Kaleidoscopic。** 在可自由操作时打开地图（也可按 F9），切换到另一个已探索区域，单击已发现的长椅，选择原版的“移动”。“取消”仍停留在地图中。
- 出发时不必坐在长椅上或站在长椅旁，也不检查是否落地；跳跃、下落或地图特殊地面判定不会单独阻止传送。目标仍限已发现的长椅，不开放任意未探索坐标。
- 保留连续传送后的地图状态刷新。修复传送失败时“移动”左侧残留勾选，失败会显示原因，并保留可重试的确认框。离开长椅时地图底部也显示传送操作说明。
- 跨区域长椅现在也能进入原版选择/确认流程。同区域长椅、原版回家命令继续走原版逻辑；跨区域长椅走带区域检查和结算的传送流程。
- 出发长椅和落地限制已放宽；剧情、危险度与天气的原版禁行条件，以及本插件的战斗、死亡、吸收/受困、解谜和地图加载保护继续保留。未发现的长椅不会开放。
- 从原版地图跨区域传送时，会执行原版长椅恢复处理和 `AUTO_SAVE_BENCH`（是否保存仍由游戏配置与条件决定）。原版剧情/入场事件也可能额外自动存档。请在试用前备份存档，不能把“未手动保存”当作撤销保证。

## 已知影响与边界

- 跨区域切换会运行原版的危险度初始化/结算、区域清理、任务与 Reels 刷新、区域 BGM 和剧情检查。危险度可能归零，敌人或未拾取掉落可能清理，公会委托可能结算；不能把它当作战斗撤退或保留现场的工具。
- 原版地图入口保留长椅的恢复与存档语义。步行计数和跨区域事件仍会执行，因此计时、消耗、治疗结果未必与正常走路完全相同。
- 传送可绕过沿途剧情触发器。虽然保留区域禁行和快速旅行检查，仍不能保证所有章节和任务组合安全。关键任务期间建议沿正常路线行动。此版本也不会伪造传送门的出入口记录，部分原版返回/复活位置仍由游戏原有记录决定。
- 原版地图只支持已发现长椅，不开放未探索地图。可以从空中出发，但落点仍由原版加载与校正处理；目标地图若没有正常落脚点，仍可能偏移或持续下落。
- 与剧情强制移动、战斗、吸收/受困、解谜、死亡或其他传送同时使用会被拦截。地图权限事件仍由游戏决定。
- 此 MOD 为第三方作品，与 Alice in Cradle 官方团队无关；不连接任何服务器。

## 卸载与配置

- 退出游戏后删除 `BepInEx/plugins/TeleportAnywhere/` 即可卸载。模组不修改原版 DLL，也不向存档追加自定义字段；已经发生的剧情、任务、掉落或自动存档变化不会因卸载回退。
- 首次启动后配置文件位于 `BepInEx/config/org.wcxawa.teleport-anywhere.cfg`。`Hotkey` 默认为 `F9`，默认打开原版地图。
- `EnableExtraPanel = true` 可重新开启 0.1.0 独立面板，F9 会改为打开该面板。它支持最多 30 个本次游玩的位置记录和返回点，读档/回标题清空，自动存档不清空；该入口不主动调用长椅恢复和 `AUTO_SAVE_BENCH`。`ShowButton` 只控制这个可选面板的入口。
- 仅针对 Windows 版 AIC 0.30 构建。没有额外提高系统版本要求，但没有验证 Vista 或其他游戏版本。

## 构建

在仓库根目录运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1 -GameRoot '<游戏根目录>'`（游戏根目录指含有 `AliceInCradle_Data` 的那一层）。加 `-Deploy` 会同时把 DLL 复制到 `BepInEx/plugins/TeleportAnywhere/`。游戏程序集和 BepInEx 仅用于本地编译，不包含在发布压缩包。
